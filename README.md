
# Bank Account Management System

## Description
A simple Java-based Bank Account Management System using OOP concepts.

## Features
- Create bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- Maintain independent balances for multiple accounts

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Files
- BankAccount.java
- Main.java

## How to Run

Compile:
javac BankAccount.java Main.java

Run:
java Main
